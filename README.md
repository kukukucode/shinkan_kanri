# shinkan_kanri

新歓期間中の参加者管理を効率化するために作成した簡易管理ツールです。

## 作った理由

新歓期間中は、参加希望者の確認、日程ごとの人数集計、ラケット貸出希望の確認などを、他の運営業務と並行して行う必要がありました。

毎回スプレッドシートを開いて必要な情報を探すのに手間がかかっていたため、まずは確認作業を減らすことを目的に、短期間で使える管理画面を作りました。

## 主な機能

* Googleスプレッドシートから参加者情報を取得
* 日程ごとに参加者を整理して表示
* 参加人数の集計
* ラケット貸出希望人数の集計
* 各日程の定員情報を表示
* LINE名、Instagram ID、テニス経験などの確認
* スマートフォンからの閲覧

## 使用技術

* HTML
* CSS
* JavaScript
* Papa Parse
* Google Sheets

Googleスプレッドシートの内容をCSVとして取得し、ブラウザ上で参加者情報と定員情報を整理して表示しています。

## 実際に作って分かったこと

このツールによって、スプレッドシートを直接確認する回数を減らし、日程ごとの参加状況を一つの画面で確認できるようになりました。

一方で、実際の新歓運営全体を支えるには、この構成では足りない部分も見えてきました。

### セキュリティ

参加者の個人情報を扱うため、ブラウザから直接データを取得するだけではなく、適切なアクセス制御が必要だと考えるようになりました。

### 認証と権限管理

このツールにはログイン機能や権限管理がありません。

運営メンバーだけが確認できる情報や、役割ごとに操作できる範囲を分けるには、認証と権限管理が必要でした。

### データ管理

Googleスプレッドシートをそのままデータ元として利用していたため、予約やキャンセルなどの更新処理や、データの整合性を管理するには向いていませんでした。

### 利用者側の機能

このツールは運営側が情報を確認するためのもので、参加者自身が登録やイベント予約、キャンセルを行うことはできませんでした。

新歓業務全体を効率化するには、運営側だけでなく参加者側も同じシステムを使えるようにする必要があると感じました。

## その後

このツールを実際の業務に合わせて作ったことで、必要な機能や改善点を具体的に把握することができました。

そのため、このツールに機能を追加していくのではなく、認証、権限管理、データベース、予約機能などを含めて構成から見直し、新しいWebアプリを作ることにしました。

## 現在の位置づけ

現在使用しているシステムではありません。

新歓業務の負担を減らすために短期間で作成し、その後のシステム設計につながった初期の管理ツールとして残しています。
